# DawnCraft Launcher 2.0 (Windows)

Mėlynos temos Electron paleidiklis, skirtas oficialiai Minecraft Java ir Bedrock versijoms paleisti.

## Funkcijos
- Java mygtukas paleidžia aptiktą oficialų Minecraft Launcher; jei neranda, atidaro oficialų atsisiuntimo puslapį.
- Bedrock mygtukas siunčia minecraft:// paleidimo užklausą; jei žaidimas neįdiegtas, atidaro oficialų Xbox puslapį.
- Vietinio profilio pasirinkimas išsaugomas lokaliai. Tai nėra autentifikacijos ar licencijos apėjimas.

## Sukūrimas
GitHub Actions automatiškai sukuria Windows EXE diegimo programą po kiekvieno push į main arba rankiniu būdu per Actions > Build DawnCraft Launcher for Windows > Run workflow.

Minecraft žaidimams reikia oficialaus įdiegimo, tinkamos licencijos ir Microsoft paskyros. Šis įrankis nėra oficialus Mojang / Microsoft produktas.
